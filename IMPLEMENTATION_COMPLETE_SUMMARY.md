## 🎓 How It Works

**For Admins:**
1. Go to Event Management
2. Click "Set as Active" on any event
3. ✨ Magic: All users now see this event on ALL forms!

**For Users:**
1. Open any Annex form
2. See blue alert showing active event
3. Submit form → Automatically linked!

**Result:** Everyone reports on the same disaster event. Zero confusion. Maximum efficiency.
