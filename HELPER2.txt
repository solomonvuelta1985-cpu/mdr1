## 🔐 SECURITY & CODING STANDARDS - MANDATORY

### MUST IMPLEMENT:
// 1. AUTHENTICATION
require_login();

// 2. CSRF PROTECTION  
if (!verify_token($_POST['csrf_token'])) {
    set_flash('Security token validation failed', 'error');
    redirect_back();
}

// 3. INPUT SANITIZATION
$data = sanitize($_POST['field']);

// 4. PDO PREPARED STATEMENTS
$stmt = db_query("INSERT INTO table (field) VALUES (?)", [$data]);

// 5. BARANGAY LOCKING CHECK (For Admins)
if (is_admin()) {
    $current_lock = get_admin_locked_barangay($_SESSION['user_id']);
    if (!$current_lock) {
        set_flash('Please select barangay from admin dashboard', 'error');
        redirect('../admin/barangay_locking.php');
    }
    $user_barangay = $current_lock;
}

- ❌ Changing original design/layout
- ❌ Raw SQL queries without prepared statements
- ❌ Skipping input validation
- ❌ Duplicate barangay selection in forms

## 🎪 CENTRALIZED BARANGAY LOCKING SYSTEM

### LOCKING WORKFLOW:
1. Admin → Selects barangay in /admin/barangay_locking.php
2. Database → Locks barangay for 1 hour
3. Users → Cannot login if their barangay is locked
4. Forms → Auto-use selected barangay, no selection needed
